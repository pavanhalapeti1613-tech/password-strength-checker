# password-strength-checker
it is python code which check password strength by
measuring it's length, 
by checking the usage of 
                        capital letters,
                        small letters,
                        numbers, special characters,
                        repeatation of same letters three or more times in a sequence.
based on these criteria it will display a strength of password.
if the password is common according to the common password list. It will inform that it is common password and suggest to change the password. 
If password is less than the required length, It will inform that the password can be guessed by brute-force and it will suggest you change the password.
If the password strength is medium or strong then the password is converted to Hash code and displayed on the screen
