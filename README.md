# password-strength-checker
1.It is python code which check password strength by
                                                     -measuring it's length, 
2.By checking the usage of 
                        -capital letters,
                        -small letters,
                        -numbers, special characters,
                        -repeatation of same letters three or more times in a sequence.
3.Based on these criteria it will display a strength of password.
4.If the password is common according to the common password list. It will inform that it is common password and suggest to change the password. 
5.If password is less than the required length, It will inform that the password can be guessed by brute-force and it will suggest you change the password.
6.If the password strength is medium or strong then the password is converted to Hash code and displayed on the screen
